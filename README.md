# 📘 Flutter Course – Section 5

This repository contains the projects for **Section 5** of the Flutter course.
Each folder is a separate Flutter project. Open the one you need in your IDE.

| Project | Topics |
|---------|--------|
| [🛒 `full_shopping_app`](full_shopping_app/) | Navigation with `go_router` (`go` / `push` / `pop`), route guards, forms & validation, `TextEditingController`, `const`, `super.key`, private State |
| [🔑 `keys`](keys/) | The relationship between Widget and State, and the importance of Keys (`ValueKey`, `ObjectKey`, `UniqueKey`) |

## Getting Started
```bash
git clone https://github.com/Atef-Mousa/flutter-course-section-5.git
cd flutter-course-section-5/<project_folder>
flutter pub get
flutter run
```

> ⚠️ Open the **project folder** (e.g. `full_shopping_app`) in your IDE, not the repository root. Every project has its own `pubspec.yaml`.
